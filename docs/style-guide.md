# TravelMate Style Guide

## Color Palette

| Element | Color | Hex Code | Usage |
|---|---|---|---|
| Primary Color | Dark Navy | #173B45 | Headings and important icons |
| Turquoise | Turquoise | #2A9D8F | Main buttons and interactive elements |
| Background | Light Cream | #F7F5EF | Application background |
| Card Color | White | #FFFFFF | Cards and white backgrounds |
| Secondary Accent | Sandy Orange | #F4A261 | Offers and prices |
| Secondary Text | Gray | #667085 | Secondary text |

## Typography

- Font Family: Poppins
- Headings: Bold
- Body Text: Regular

## Spacing and Shape

- Consistent spacing throughout the application
- Rounded cards
- Rounded buttons

## Components

- Material 3 Buttons
- Material 3 Cards
- Text Fields
- Navigation Components
