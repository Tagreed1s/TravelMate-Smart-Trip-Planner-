TravelMate ✈️

About the Project

TravelMate is a travel-planning mobile application that helps users explore destinations, create personalized trips, organize daily itineraries, and manage travel expenses.

Main Features

* Login and Sign Up
* Destination Details
* Create Trip
* Daily Itinerary
* Trip Cost Summary
* Saved Trips
* Favorites

UI/UX Design

The application uses a consistent design system with the following colors:

* Dark Navy: #173B45
* Turquoise: #2A9D8F
* Light Cream: #F7F5EF
* White: #FFFFFF
* Sandy Orange: #F4A261
* Gray: #667085
